# Catálogo de demostración, versión 2026-10

157 definiciones explícitas de servicios, repuestos y consumibles y un concepto inactivo para filtros. El lote se construye desde cero; no hereda conceptos/precios genéricos del catálogo mínimo. Solo se carga en una base Demo vacía y no cambia precios de documentos emitidos. No es inventario ni una tabla de compatibilidad por motor/VIN.

Incluye frenos delanteros y traseros (discos y campanas diferenciados), los cuatro filtros, service completo de mano de obra y sustituciones individuales, lubricantes por litro, refrigeración, electricidad, suspensión, dirección, embrague, distribución, ruedas y climatización. El service completo no incluye materiales; no sumar además servicios individuales equivalentes. La carga de aire acondicionado sí declara que incluye la carga; no duplicar el refrigerante.

Los importes son referencias académicas redondeadas, no cotizaciones vigentes garantizadas. La aplicación muestra el precio propuesto y el técnico debe confirmar aplicación, unidad, norma y precio antes de enviarlo. No se inventa un precio preciso para cada modelo ni se afirma que todos los vehículos equipan discos traseros o el mismo aceite.
